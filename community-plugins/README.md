# Community plugins

Plugins for the **official** LearnHarness desktop app (0.6.0 or newer). They're ready to
use: no build step, and you don't need to build this fork. Copy a plugin into your
plugins folder and turn it on in **Settings → Community plugins**.

| Plugin | What it does |
| --- | --- |
| [PDF page ranges](pdf-range/README.md) | Attach only a page range of a PDF (cut with qpdf), so big PDFs don't fill the conversation's context. |

Each plugin's README covers what it does, requirements, install and troubleshooting.

> Community plugins are trusted local code, not sandboxed: they run with your user's
> permissions. Only install plugins from people you trust, and feel free to read the
> code first; each one is a few small files.
